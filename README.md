# 🚀 [프로젝트명 : WTW] - Backend

> **개발 기간:** 2026.08  
> **팀 구성:** 기획/디자인 1명, 프론트엔드 3명, 백엔드 2명(본인)  
> **서비스 소개:** 방문 카드 기반 고객 맞춤형 쇼핑 큐레이션 및 직원 응대 가이드 서비스 (AI로 온라인의 취향을 오프라인의 개인화된 럭셔리 경험으로 연결하는 솔루션)

---

## 🛠️ Tech Stack (Backend)
* **Language:** Java (JDK 17)
* **Framework:** Spring Boot, Spring Data JPA
* **Database:** MySQL / PostgreSQL
* **External API:** OpenAI API
* **Infrastructure:** AWS / Vercel

---

## 📌 주요 담당 역할 및 기여 내역 (Backend)

### 1. 데이터베이스 설계 및 도메인 모델링
* MySQL / PostgreSQL을 활용하여 고객의 방문 카드 데이터, AI 추천 결과, 상품 정보를 관리하기 위한 핵심 ERD 설계
* Spring Data JPA를 이용한 엔티티 클래스 작성 및 연관관계 매핑

### 2. OpenAI API 연동 및 맞춤형 AI 서비스 로직 구현
* **방문 카드 기반 AI 한 줄 요약:** 사용자가 작성한 방문 카드 내용을 OpenAI API로 분석하여, 고객의 쇼핑 목적과 분위기를 파악하는 요약 텍스트 생성 로직 구현 *(ex. "오늘은 세련된 클래식의 품격 속에서...")*
* **AI 맞춤 동선 추천:** 응답 내용을 바탕으로 고객의 목적에 맞는 3가지 Zone 추천 알고리즘 및 데이터 처리 구현
* **AI 개인화 상품 추천:** 추천된 3개 Zone별로 취향에 맞는 상품을 각각 3개씩(총 9개) 선별하여 제공하는 데이터 구조화 및 응답 로직 개발
* **직원 응대 가이드 생성:** AI 분석 결과(고객 분석, 응대 방식 제안, 첫 응대 멘트)를 가공하여 현장 직원이 빠르게 파악할 수 있도록 API 엔드포인트 구축

### 3. RESTful API 설계 및 예외 처리
* 프론트엔드와의 원활한 협업을 위한 Spring Controller, Service 계층 기반의 API 설계
* 외부 AI API 호출 시 발생할 수 있는 지연 및 예외 상황에 대비한 안정적인 예외 처리 로직 구현

### 4. 서버 배포
* AWS 환경을 활용한 백엔드 서버 구축 및 배포
